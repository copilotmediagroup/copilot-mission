- [ ] Guard sees **Start Patrol** after route state.
- [ ] Start Patrol creates the authoritative arrival/active mission state.
- [ ] Checkpoints can only be completed in order.
- [ ] Required photos block Main Entrance and Rear Loading Dock completion.
- [ ] Draft incidents block checkpoint completion.
- [ ] Each completion stores time, evidence summary, and best-effort GPS.
- [ ] Refresh restores the correct checkpoint.
- [ ] Agency/client timeline receives one checkpoint event per completion.
- [ ] Sixth checkpoint transitions to review.
- [ ] Existing Unified Map, Dispatch, Client Tracking, and Reporting flows still operate.
