# RC1.4 Browser Acceptance Gate

The recovered foundation is accepted only after all items pass in Bolt or the deployed site.

- [ ] Application starts without a white screen
- [ ] No missing local import/export error
- [ ] Google map loads
- [ ] Real Google roads and labels render
- [ ] Property marker renders at verified property coordinates
- [ ] Guard marker renders from live/device coordinates
- [ ] Google driving directions request succeeds
- [ ] Blue road-following route renders between guard and property
- [ ] Distance and duration populate when a route exists
- [ ] No route is shown after mission completion
- [ ] Browser console contains no map-blocking error

Do not add Marketplace, Operations, notification, proximity, or dispatch enhancements until every box is checked.
