# RC2.1A Acceptance Gate

- [ ] Complete Checkpoint changes to the next checkpoint immediately.
- [ ] A failed checkpoint save restores the previous checkpoint and shows an error.
- [ ] Patrol timer and Review & Submit time remain synchronized.
- [ ] Completed mission duration matches the same mission clock.
- [ ] Client-uploaded property image appears on assignment and arrival.
- [ ] Missing property photo displays a neutral property state, never stock media.
- [ ] Agency All, Open Jobs, Priority, Emergency, and My Guards show distinct counts/content.
- [ ] Agency map is a real Google map.
- [ ] My Guards hides marketplace jobs.
- [ ] Priority and Emergency hide standard jobs.
- [ ] Guard, Client, mission, reporting, and presence regressions pass.
