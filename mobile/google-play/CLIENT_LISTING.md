## Full description
CO PILOT SECURITY gives approved clients one place to request and manage professional security service through the Co Pilot Security Marketplace.

Request security for a property, follow assigned coverage during an active mission, receive mission and service updates, review activity and evidence, and manage service billing from a secure client workspace.

Key features include security-service requests, active mission tracking, assignment and progress notifications, mission activity history, evidence/report access, property management, and billing tools.

CO PILOT SECURITY is designed for real-world security services. Availability and service coverage depend on participating providers and approved marketplace access.
