# Play Console Submission Checklist

## Developer account
- Developer identity verified
- Organization/legal details accurate if applicable
- Package names registered: com.copilotsecurity.client and com.copilotsecurity.guard

## Each app
- App created in Play Console with exact permanent package name
- Store listing copy entered
- App icon + feature graphic + phone screenshots uploaded
- Privacy policy URL entered
- App access/reviewer credentials entered
- Ads declaration completed
- Target audience/content completed
- Content rating questionnaire completed
- Data safety completed and reconciled with privacy policy
- Account deletion URL supplied where required
- Sensitive permission declarations completed where Play requests them
- Signed API 36 AAB uploaded to Internal testing
- Play App Signing configured
- Physical-device certification completed against exact release candidate
- FCM push canary passed
- Pre-launch report reviewed
- Production rollout only after blockers are clear
