# Client Mission Selection Authority Contract — RC2.1C

The Client portal presents exactly one primary mission experience. Selection is lifecycle-based, never merely recency-based.

- In-progress fulfillment outranks unclaimed requests because it requires immediate client awareness.
- A new open request outranks completed history.
- Completed history is a fallback only when no live or open request exists.
- Cancelled jobs are never selected.
- Report publication cannot promote a completed job above a live/open job.
